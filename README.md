An open-world crime game in the spirit of GTA 6, set on the invented
Caribbean island of **Isla Fortuna**. Dante Reyes, getaway driver,
runs twelve story jobs for the fixer Auntie Marisol — from a first
taxi fare to the Fortuna heist at the Gilded Crown Casino — then free
roam across the island.

## What's in the game

- **An island to explore on foot, by car and by boat**: Fortuna City,
  the Gilded Mile casino strip, Old Town, the fishing harbour, Palm
  Beach, the jungle and an airstrip — with traffic, pedestrians,
  palms, parks and a plaza.
- **12 story jobs with a real arc**: fares, package runs, getaways,
  a boat pickup, a street race, a turf war, a scanner heist, a
  blackout delivery, an escort, three vault keys and the finale.
- **A wanted level with police who respond** — patrol cars, police
  boats, roadblocks — plus a **heat meter** the island remembers
  between jobs. Wanted stars come from heat thresholds, so a bumped
  pedestrian is a fine, not a felony.
- **A day/night cycle with weather**: dawn, noon, golden sunset,
  night lamps and island rain.
- **A crew to hire**: Mara the Driver, Leo the Lookout, Ada the
  Hacker — each changes how the island plays.
- **Side work**: taxi fares, street races, and 8 golden doubloons
  hidden around the island.
- **A HUD with a live minimap**, wanted stars, heat, the clock, the
  weather and the mission objective; start screen, pause menu, and
  save/load in the browser.

## Controls

WASD / arrows — move and drive · E — enter a car or boat · Space —
punch · Shift — run · P — pause · M — mute · H — horn · R — retry a
failed job · 1/2/3 in pause — hire crew.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network — the
game is plain static files under `game/`.
